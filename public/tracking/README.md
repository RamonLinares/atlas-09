# Body tracking assets

`pose_landmarker_lite.task` is Google's MediaPipe Pose Landmarker Lite, float16, version 1:
https://storage.googleapis.com/mediapipe-models/pose_landmarker/pose_landmarker_lite/float16/1/pose_landmarker_lite.task

Model and API documentation: https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker

`runtime/` is generated by `scripts/prepare-pose-runtime.mjs` from the pinned `@mediapipe/tasks-vision` npm package, version 1.0.1 (Apache-2.0). Both development startup and production builds prepare these files. Do not edit generated runtime files.

The classic worker loads the JavaScript runtime, WebAssembly and model from this site's own origin. Video frames are transferred to that worker for inference and disposed immediately after each inference. The application does not record frames or transmit them to a server. The microphone is never requested.
