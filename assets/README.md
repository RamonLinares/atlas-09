# Source assets

Original concepts, generation prompts, provider receipts, source meshes, and retopology outputs are preserved here so the character pipeline can be inspected and reproduced locally.

ATLAS uses `concepts/`, `source/`, and `retopo/`. The other characters have corresponding folders under `aether-02/`, `seraph-03/`, `ronin-04/`, and `scorpio-05/`. Selected Quaternius motions and original CC0 notices are in [animations/quaternius](animations/quaternius/README.md).

The five mecha asset collections are [CC0 — free for commercial and noncommercial use without attribution](../ASSET-LICENSE.md). Historical provider URLs in receipts may expire; the downloaded files are the reproducible inputs. The web viewer does not call generation providers or require their API keys.
