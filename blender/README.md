# Blender projects

Open a character's `.blend` in Blender 5.1 or newer. Each delivery contains its rig, packed textures, animation actions, and an inspection/rendering stage. Physical dimensions are retained in meters. The runtime viewer separately scales each character for display.

All seven mecha Blender projects, rigs, textures and animations are [CC0 — free for commercial and noncommercial use without attribution](../ASSET-LICENSE.md).

Use the Action Editor to select clips. The character documents at the repository root describe each rig and its rebuild sequence. Scripts can overwrite existing deliveries; save your work before rebuilding. Older source snapshots under `versions/` are retained for provenance. Exported GLBs under `public/models/` exclude the Blender studio stage.
